# Personal Finance Analysis
An interactive Excel dashboard for analyzing personal income, expenses, savings, investments, and surplus trends across months and years.
## Project Overview
This project provides a visual personal finance dashboard built in Microsoft Excel. It helps track spending behavior, identify high-expense categories, compare savings vs investments, and monitor overall financial efficiency using surplus rate trends.
The dashboard includes slicers for flexible filtering by year and month, making it useful for both detailed analysis and presentation.

## Workbook Structure
The workbook contains the following sheets:
- 'Dashboard' - Main interactive dashboard with charts, slicers, and key takeaways
- 'Pivots' - Pivot tables used to power dashboard charts and summaries
- 'Transformed_Data' - Cleaned long-format data used for analysis
- 'monthly_spending_dataset_2020_2025' - Monthly source dataset with category-level expense columns

## Data Preparation Note
The workbook uses two related data tables:
- Original monthly-level dataset for income, savings, expenditure, and surplus analysis
- Transformed long-format dataset from Power Query for category-wise expense analysis
Separate slicers are used where required because the PivotTables are connected to different source tables. This keeps the dashboard flexible while supporting multiple levels of analysis.

## Charts Included
The dashboard contains the following visuals:
1. **Monthly Income vs Spend vs Surplus**
   - Compares income, total expenditure, and surplus by month.

2. **Spend by Category**
   - Shows category-wise expense distribution.

3. **Savings vs Investments**
   - Tracks savings and investment amounts over time.

4. **Highest Spend Months**
   - Highlights the months with the highest total expenditure.

5. **Surplus Rate Trend by Year**
   - Shows how financial efficiency changes year over year.
